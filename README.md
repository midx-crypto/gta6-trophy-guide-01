Leonida Nights is an offline GTA 6 trophy guide and tracker for PlayStation 5: all 55 trophies with their official names, descriptions and grades, a cited guide for each one, a seven-stage platinum roadmap, a missable watch list, a spoiler mode that hides story trophies until earned, and a checklist whose progress is saved in the browser and can be exported and imported.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network: the guide loads only its own files.
